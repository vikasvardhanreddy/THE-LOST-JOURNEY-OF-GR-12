# THE LOST JOURNEY OF GR audio

All WAV files in this folder are original procedural audio generated for this project by `tools/generate_audio.py`. They use no third-party samples, melodies, paid services, or external assets. The generator requires only Python's standard library.

The music beds are mono 22.05 kHz PCM and are looped by `JourneyAudio`; short sound effects are also mono PCM to keep mobile playback and storage light. Godot imports and packs these resources for the Android export.

Music: menu theme and one ambient bed for each of the five chapters.

Effects: footsteps, UI click, item/coin pickup, puzzle solved, door movement, and interaction feedback.
